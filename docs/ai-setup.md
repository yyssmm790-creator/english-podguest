# 내 이야기 AI 연결 (Netlify)

코드는 API 키 없이 빌드/배포됩니다. 실제 생성에는 OpenAI API 키와 사용 가능한 API 크레딧이 필요합니다. ChatGPT 구독과 API 요금은 별개입니다.

## Netlify에서 설정

1. `my-english-podguest` 프로젝트의 **Project configuration → Environment variables**를 엽니다.
2. **Add a variable**에서 다음 항목을 저장합니다.
   - Key: `PODGUEST_AI_KEY`
   - Value: 본인의 OpenAI API 키. 채팅이나 GitHub에 붙여넣지 않습니다.
   - Scope를 고를 수 있다면 **Functions**에 적용하고 Production 배포에 값을 설정합니다.
3. 기본 모델은 `gpt-4.1-mini`입니다. 다른 구조화 출력 지원 모델을 쓰려면 선택적으로 `PODGUEST_AI_MODEL`을 설정합니다.
4. **Deploys → Trigger deploy**에서 최신 브랜치를 다시 배포합니다. 환경변수 변경은 새 함수 배포에 반영되어야 합니다.
5. **Published** 후 사이트를 새로고침합니다. 예시가 아닌 짧은 일상을 입력하고 ‘내 이야기로 영어 만들기’를 누릅니다.
6. 1·2·3단계를 바꾸어 대화문과 팟게스트 대본을 확인합니다. 같은 입력의 단계 변경은 그 화면에서는 추가 API 요청을 하지 않습니다.

키를 설정하기 전에는 예시 이야기는 작동하지만 자유 입력의 실제 생성은 `ai_not_configured` 안내가 나옵니다. 브라우저에 키를 입력하는 UI나 공개 API 키는 없습니다.

## 동작

- 한국어 음성 입력은 브라우저 음성 인식이 글로 변환합니다. 이 앱의 대본 API에는 글만 전송합니다. 브라우저 음성 인식 서비스의 처리 방식은 해당 브라우저 정책을 따릅니다.
- `POST /api/story`에 `{ "story": "내 이야기" }`를 보냅니다. 입력은 최대 2,000자입니다.
- Netlify의 `netlify/functions/story.mjs`가 `lib/story-service.js`를 호출합니다. 로컬 Node 서버도 같은 서비스를 사용합니다.
- 앱 서버가 OpenAI Chat Completions API에 3단계의 팟게스트/대화문을 엄격한 JSON 구조로 요청합니다. `store:false`이며 앱 서버에는 이야기를 파일/DB로 저장하지 않습니다. API 공급자의 데이터 정책은 별도입니다.
- 결과를 검증한 후 브라우저에 전달합니다. 잘못되거나 잘린 결과를 예시 대본으로 바꿔서 성공했다고 표시하지 않습니다.
- 1단계: A1의 아주 짧은 문장. 2단계: A2의 자연스러운 일상 표현. 3단계: B1의 조금 더 풍부한 표현. 단계가 바뀌어도 사실을 추가하지 않도록 지시합니다.
- 대화는 내 이야기를 바탕으로 생성한 질문/예시 답변을 연습합니다. 이후 마이크 답변의 의미를 AI가 매번 해석해 새 질문을 만드는 실시간 챗봇은 아닙니다.
- 취소/오류 시 원래 입력을 유지합니다. 완료한 결과는 현재 페이지 메모리에 캐시합니다. 새로고침하면 재생성이 필요할 수 있습니다.
- 대본을 가리고 직접 녹음한 경우에만 팟게스트 일기장에 원래 이야기, 생성 대본, 제목, 단계와 음성을 브라우저 로컬로 저장합니다.

## 비용/공개 운영

- 한 번의 생성으로 3단계를 함께 받습니다. API 사용료는 계정에 청구됩니다. OpenAI 프로젝트의 예산/사용량 설정을 함께 확인하세요.
- 길이/시간 제한, 같은 출처 검사와 IP 기반 제한을 넣었습니다. 제한은 실행 중인 함수 인스턴스마다 10분에 6번으로 동작하는 best-effort 제한이며 분산 환경의 전역 예산 한도가 아닙니다. 공개 사용량이 늘면 인증/중앙 제한이 필요합니다.
- 공급자 오류 메시지, 키, 원래 이야기를 서버 로그에 출력하지 않습니다. `GET /api/story`는 설정 유무만 반환합니다.

## 로컬 실행

Node.js 22 이상에서 환경변수를 주입하거나, `.env.example`을 복사한 `.env`를 사용합니다. `.env`는 Git에서 제외합니다.

```sh
npm run build
node --env-file=.env server.js
```

`npm start`는 이미 프로세스에 설정된 환경변수를 사용하며 `.env`를 자동으로 읽지 않습니다. `npm test`는 실제 유료 요청 없이 모의 공급자로 검증합니다.

## 이번 검증 범위

- Node 테스트 16개 통과: 입력/출처/출력 검증, 세 단계 요청, 설정 없음, 공급자 오류/시간 초과/거절, 호출 제한, Netlify 어댑터 등.
- Chromium의 iPhone 화면 설정: 자유 입력 → API 결과 → 단계 전환, 대화문/혼자 읽는 대본 분리, 말하기 시작/종료, 음성 입력의 글 전달, 취소/실패 시 보존, 녹음 일기장의 제목·원문·단계, 모바일 가로 넘침 없음.
- AI 공급자는 테스트 응답으로 대체했습니다. 실제 API 키가 실행 환경에 없으므로 유료 모델의 실제 문장 품질/생성 지연과 배포된 Netlify 함수의 실제 공급자 연결은 아직 검증하지 않았습니다. 키 설정 후 실제 이야기로 확인해야 합니다.
