# Podguest

내 일상을 쉬운 영어로 말해보는 모바일 중심 스튜디오입니다. 한국어로 말하거나 글로 입력한 이야기를 바탕으로 **3단계의 영어 대화문과 팟게스트 대본**을 만듭니다.

## 실제 AI 연결

**Netlify 환경변수 `PODGUEST_AI_KEY`를 Functions에 설정하고 재배포해야 자유 입력의 실제 AI 생성이 활성화됩니다.** API 키를 채팅, GitHub, 브라우저 코드에 넣지 않습니다. 기본 모델은 `gpt-4.1-mini`입니다. [설정 안내](docs/ai-setup.md)를 참고하세요. API 사용료는 별도입니다.

키 없이도 커피·직장·산책의 수작업 예시를 1·2·3단계로 둘러볼 수 있습니다. 예시는 명확히 표시하며, 자유 입력을 예시로 대체해 AI 생성이라고 표시하지 않습니다.

## 사용 흐름

1. 스튜디오에서 한국어로 이야기하거나 글로 남깁니다. 입력창의 ‘새로 쓰기’를 누르면 진행 중인 입력/생성을 멈추고 초안만 비운 뒤 바로 새 글을 쓸 수 있습니다. 빈 초안도 기억하므로 다시 열 때 이전 연습이 덮어쓰지 않습니다. 보관한 대본과 일기장은 지우지 않습니다. 첫 화면에는 ‘이전에 보관한 대본’만 접어서 표시하며 그 안에서 중단한 연습도 다시 열 수 있습니다. 음성 입력은 브라우저 음성 인식을 사용하며, 미지원 시 글 입력으로 안내합니다.
2. ‘내 이야기로 영어 만들기’로 3단계를 함께 생성합니다. 작성 중인 글과 현재 대본만 브라우저에 기억하여 다음 접속 시 이어볼 수 있습니다. 새 연습마다 일기장 항목이나 대본 목록을 자동으로 추가하지 않습니다. 이전 버전에서 보관한 대본과 기존 일기장은 유지합니다.
   - 1단계: 아주 짧고 쉬운 A1 문장
   - 2단계: 자연스러운 A2 일상 표현
   - 3단계: 조금 더 풍부한 B1 표현
3. AI와 대화하기: 기본 Nova로 바로 시작하며 음성을 먼저 고를 필요가 없습니다. 버튼은 ‘시작 ↔ 멈춤’ 두 상태입니다. 답변 도중 멈췄다면 같은 질문을 다시 읽지 않고 듣기로 재개하고, AI 질문 도중 멈췄다면 같은 질문을 읽습니다. 종료 처리 중 빠른 재시작도 한 번의 클릭으로 예약해 재개합니다. 실제 말소리 후 약 3초의 침묵에 다음 질문으로 넘어갑니다. 설명 문구 대신 음성 파형과 🗣️ 듣기 아이콘을 사용하며 녹음은 일기장에 자동 저장하지 않습니다. 설정은 작은 톱니 안에 있고 질문 건너뛰기는 진행 중 작은 › 아이콘으로 제공합니다. 모바일에서는 질문·답변 영역만 내부 스크롤하고 주요 조작은 한 화면에 유지합니다. 발화의 의미를 매번 해석하는 자유 대화/발음 평가는 아직 없습니다.
4. 팟게스트 되어보기: 대본을 보면서 오른쪽 위 작은 마이크로 연습하고 아래 🔊(영어 읽기)·🗣️(내 목소리 듣기)·↻(다시 연습)를 사용합니다. 연습 음성은 메모리에만 보관하며 끝나자마자 🗣️로 들을 수 있습니다. 대본을 가리면 원래 큰 스튜디오 마이크와 🗣️·💾·↻를 표시합니다. 마음에 든 가린 대본 녹음에서 💾를 눌러야 대본·원문·음성·단계가 한 세트로 일기장에 저장됩니다. 종료/홈 이동/다시 연습은 자동 저장하지 않습니다. 웹을 닫았다 열면 마지막 대본과 표시/가리기 상태가 복원되며 마이크나 재생은 자동 시작하지 않습니다. 저장하지 않은 음성은 창을 닫으면 사라집니다.
5. 일기장은 제목 수정, 다시 듣기, 다운로드, 녹음파일만 삭제, 날짜별 기록을 제공합니다. 내려받기 아래의 삭제 버튼은 음성 Blob만 없애고 제목·이야기·대본·연습 기록은 유지합니다. 재생기의 다운로드/재생속도 메뉴 대신 별도 내려받기·삭제 동작을 제공하며, 기본 메뉴 숨김은 브라우저 지원에 따릅니다. 원래 이야기·대본·단계·음성을 해당 브라우저 IndexedDB에 저장하며 계정/기기간 동기화는 없습니다. 브라우저 데이터를 지우면 사라질 수 있으므로 소중한 녹음은 내려받아 보관합니다.

## 화면과 음성

- 편안한 스튜디오 배경과 모바일 터치 영역을 사용합니다. 입력 화면과 모드 선택/연습 화면은 순서대로 전환합니다.
- AI 형태는 빛·물결·구름 중 바꿀 수 있고 **AI가 말할 때만** 움직입니다. 사용자 목소리는 별도의 파형에 표시합니다. 사람 이미지/입 애니메이션은 사용하지 않습니다.
- 모든 기기에서 OpenAI 공통 AI 음성을 사용합니다. 기본 Nova, 추가 Shimmer/Onyx/Echo 네 가지이며 기기 설치 음성으로 바꾸지 않습니다. AI 음성임을 설정에 표시합니다. 인터넷과 API 사용량이 필요합니다.
- `PODGUEST_AI_KEY` 하나로 대본과 음성을 모두 연결합니다. `/api/speech`는 Netlify Function과 로컬 서버에서 같은 `lib/speech-service.js`를 사용하고 키를 브라우저에 전달하지 않습니다. 음성 모델은 `gpt-4o-mini-tts`, 출력은 MP3입니다. 예전 Azure 설정은 사용하지 않습니다.
- 같은 목소리/문장을 다시 듣는 경우 현재 페이지에서 받은 음성을 재사용합니다(최대 16개/10MB, 새로고침 시 해제). API 연결·재생 오류는 안내하며, 기기 음성으로 바꾸거나 공통 목소리를 영구 삭제하지 않습니다. iOS에서 첫 클릭으로 해제한 동일한 오디오 플레이어를 다음 질문에도 재사용합니다.
- 음악은 자체 생성 어쿠스틱 기타 스타일 반주 10개, 각각 약 2분(총 약 20분)입니다. ON 이후 한 곡씩 끝까지 이어 듣고 10번 뒤 처음으로 돌아옵니다. 말하기·녹음 중에도 자동 음소거하지 않고 OFF에서 중지합니다. 음원은 같은 사이트에서 필요할 때 불러옵니다. 유튜브/상업 음원을 추출한 것이 아닙니다.
- 오른쪽 위 공유 버튼은 스튜디오 미리보기용 고정 링크 `https://my-english-podguest.netlify.app/?share=studio-v2`를 보냅니다. 휴대폰 기본 공유창을 사용하고, 미지원/실패 시 링크를 복사하며 복사도 막히면 직접 선택할 수 있는 창을 보여줍니다. 개인 대본이나 녹음은 공유하지 않습니다. 실제 스튜디오 화면 1200×630 PNG와 Open Graph 메타 태그가 있으며 최종 미리보기 표시는 공유 앱의 캐시·설정에 따릅니다.

## 실행과 배포

Node.js 22 이상, 런타임 npm 의존성 없이 동작합니다.

```sh
npm start
```

기본 포트 3000, `PORT`로 변경 가능합니다. `npm run build`는 `public/index.html`을 빌드합니다. CSS/JS는 HTML에 포함하고 음악/공유 이미지는 별도 파일입니다. 외부 글꼴 연결이 없어도 시스템 글꼴로 표시됩니다.

- Netlify 배포 설정: `netlify.toml`, 빌드 `npm run build`, 게시 폴더 `public`.
- Netlify Functions: `/api/story`, `/api/speech`, `/api/voice-status`에 각각 대본 생성·공통 음성·연결 상태를 제공합니다. 기존 `PODGUEST_AI_KEY`의 Functions 범위 설정을 그대로 재사용합니다.
- 공유 AI 서비스: `lib/story-service.js`, 입력/모델 출력 검증과 오류 처리를 담당합니다.
- `public/index.template.html`, `public/app.js`, CSS 파일을 수정한 후 빌드합니다. `public/index.html`은 생성물입니다.
- 음원 재생성: `scripts/generate_acoustic_playlist.py`에만 NumPy/ffmpeg가 필요하며 일반 빌드에는 필요하지 않습니다.

## 확인

```sh
npm run check
npm test
```

현재 Node 테스트는 16개이며 유료 요청 없이 모의 공급자로 실행합니다. 실제 AI 키 연결과 생성 문장 품질은 키 설정 후 검증해야 합니다. [AI 설정/검증 범위](docs/ai-setup.md), [모바일 점검 범위](docs/mobile-check.md)를 참고하세요. 휴대폰 화면 모의 점검은 실제 iPhone Safari/Android Chrome의 마이크·스피커 검증과 다릅니다.

Netlify가 배포 뒤 삽입하는 ‘Powered by Netlify’ 배지는 명시적 배지 선택자와 branding 링크 탐지로 숨깁니다. 저장소 원본에는 배지가 없으며 실제 호스팅 삽입 형태는 배포 후 확인해야 합니다. 임의의 Netlify 링크나 앱 콘텐츠를 제거하지 않습니다.
