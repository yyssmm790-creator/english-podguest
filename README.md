# Podguest

내 일상을 쉬운 영어로 말해보는 모바일 중심 스튜디오입니다. 한국어로 말하거나 글로 입력한 이야기를 바탕으로 **3단계의 영어 대화문과 팟게스트 대본**을 만듭니다.

## 실제 AI 연결

**Netlify 환경변수 `PODGUEST_AI_KEY`를 Functions에 설정하고 재배포해야 자유 입력의 실제 AI 생성이 활성화됩니다.** API 키를 채팅, GitHub, 브라우저 코드에 넣지 않습니다. 기본 모델은 `gpt-4.1-mini`입니다. [설정 안내](docs/ai-setup.md)를 참고하세요. API 사용료는 별도입니다.

키 없이도 커피·직장·산책의 수작업 예시를 1·2·3단계로 둘러볼 수 있습니다. 예시는 명확히 표시하며, 자유 입력을 예시로 대체해 AI 생성이라고 표시하지 않습니다.

## 사용 흐름

1. 스튜디오에서 한국어로 이야기하거나 글로 남깁니다. 음성 입력은 브라우저 음성 인식을 사용하며, 미지원 시 글 입력으로 안내합니다.
2. ‘내 이야기로 영어 만들기’로 3단계를 함께 생성합니다. 이후 같은 이야기의 단계만 바꾸면 현재 페이지에서는 추가 AI 요청 없이 전환합니다.
   - 1단계: 아주 짧고 쉬운 A1 문장
   - 2단계: 자연스러운 A2 일상 표현
   - 3단계: 조금 더 풍부한 B1 표현
3. AI와 대화하기: 내 이야기로 만든 질문과 예시 답변을 연습합니다. 시작 → 일시정지 → 이어하기이며, 답변 중 일시정지했다면 질문을 반복하지 않고 듣기로 재개합니다. 질문 재생 중 일시정지한 경우 같은 질문을 다시 읽습니다. 실제 말소리 후 약 3초의 침묵에 다음 질문으로 이어지며 수동 ‘다음 질문’도 가능합니다. 발화의 의미를 매번 해석하는 자유 대화/발음 평가는 아직 없습니다.
4. 팟게스트 되어보기: 대본을 보면서 ‘시작하기’로 내 목소리 파형만 확인하고, 같은 버튼으로 마칩니다. 이 연습은 녹음·저장하지 않습니다. 대본 가리기 → 큰 마이크 클릭 → 녹음 → 다시 클릭하면 일기장에 자동 저장합니다.
5. 일기장은 제목 수정, 다시 듣기, 다운로드, 날짜별 기록을 제공합니다. 원래 이야기·대본·단계·음성을 해당 브라우저 IndexedDB에 저장하며 계정/기기간 동기화는 없습니다. 브라우저 데이터를 지우면 사라질 수 있으므로 소중한 녹음은 내려받아 보관합니다.

## 화면과 음성

- 편안한 스튜디오 배경과 모바일 터치 영역을 사용합니다. 입력 화면과 모드 선택/연습 화면은 순서대로 전환합니다.
- AI 형태는 빛·물결·구름 중 바꿀 수 있고 **AI가 말할 때만** 움직입니다. 사용자 목소리는 별도의 파형에 표시합니다. 사람 이미지/입 애니메이션은 사용하지 않습니다.
- 기본 영어 음성은 기기의 실제 영어 목소리를 표시합니다. 목록이 비어 있으면 기기 기본 영어 재생을 시도합니다. 목소리의 제공/발음/음량은 기기별로 다릅니다.
- 선택적으로 Node 서버의 `SPEECH_KEY`, `SPEECH_REGION`을 설정하면 Azure Speech의 여성 5개/남성 4개 카탈로그를 사용할 수 있습니다. 정적 Netlify 사이트는 이 선택적 Azure 서버를 배포하지 않고 기기 음성을 사용합니다.
- 음악은 자체 생성 어쿠스틱 기타 스타일 반주 10개, 각각 약 2분(총 약 20분)입니다. ON 이후 한 곡씩 끝까지 이어 듣고 10번 뒤 처음으로 돌아옵니다. 말하기·녹음 중에도 자동 음소거하지 않고 OFF에서 중지합니다. 음원은 같은 사이트에서 필요할 때 불러옵니다. 유튜브/상업 음원을 추출한 것이 아닙니다.
- 링크 공유용 실제 스튜디오 화면 1200×630 PNG와 Open Graph 메타 태그가 있습니다. 기존 메신저 미리보기 캐시는 별도로 갱신될 수 있습니다.

## 실행과 배포

Node.js 22 이상, 런타임 npm 의존성 없이 동작합니다.

```sh
npm start
```

기본 포트 3000, `PORT`로 변경 가능합니다. `npm run build`는 `public/index.html`을 빌드합니다. CSS/JS는 HTML에 포함하고 음악/공유 이미지는 별도 파일입니다. 외부 글꼴 연결이 없어도 시스템 글꼴로 표시됩니다.

- Netlify 배포 설정: `netlify.toml`, 빌드 `npm run build`, 게시 폴더 `public`.
- Netlify Function: `netlify/functions/story.mjs`, `/api/story`로 연결합니다.
- 공유 AI 서비스: `lib/story-service.js`, 입력/모델 출력 검증과 오류 처리를 담당합니다.
- `public/index.template.html`, `public/app.js`, CSS 파일을 수정한 후 빌드합니다. `public/index.html`은 생성물입니다.
- 음원 재생성: `scripts/generate_acoustic_playlist.py`에만 NumPy/ffmpeg가 필요하며 일반 빌드에는 필요하지 않습니다.

## 확인

```sh
npm run check
npm test
```

현재 Node 테스트는 16개이며 유료 요청 없이 모의 공급자로 실행합니다. 실제 AI 키 연결과 생성 문장 품질은 키 설정 후 검증해야 합니다. [AI 설정/검증 범위](docs/ai-setup.md), [모바일 점검 범위](docs/mobile-check.md)를 참고하세요. 휴대폰 화면 모의 점검은 실제 iPhone Safari/Android Chrome의 마이크·스피커 검증과 다릅니다.
